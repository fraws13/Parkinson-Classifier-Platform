# Group 2 SSC — AI Activity Logs

Dedicated folder for tracking every **substantive** activity performed with Artificial Intelligence tools, as required by the course (*AI Tracking*).

## Rules

1. Add one row to [`index.md`](index.md) for each relevant AI-assisted session.
2. Create a session file under the deliverable folder using [`templates/session_template.md`](templates/session_template.md).
3. Always fill **Human review**: what was accepted, edited, or rejected by the team.
4. Log the same day the work is done.
5. Do **not** paste full chat transcripts; keep a short summary + paths + decisions.
6. Do **not** store secrets, API keys, or credentials.
7. Skip trivial autocomplete; log only sessions that produced architecture text, code, estimates, slides, or reports that entered the repository.

## Tools in scope

Cursor, ChatGPT, Copilot, and any other generative AI used for project work.

## Naming

Organize by deliverable folder. Session files:

`first_deliverable_<short-topic>.md`

Example: `first_deliverable/first_deliverable_ml-pipeline.md`

For later phases use the same pattern, e.g. `second_deliverable/second_deliverable_<topic>.md`.
